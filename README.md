# Puri — Daily Life Solver for Korea

> 풀이 (puri) — Korean for "explanation" or "solution"

A pocket AI assistant that helps foreigners navigate daily life in South Korea.
Snap a photo of anything confusing — trash bins, washing machines, subway machines — and get 
instant step-by-step guidance in English.

## Tech Stack
- Kotlin + Jetpack Compose
- Clean Architecture (MVVM + MVI)
- Gemini AI (image + text understanding)
- Hilt, Room, DataStore, CameraX
- Coroutines + Flow

## Setup
1. Clone the repo
2. Add your Gemini API key to `local.properties`:
```
   GEMINI_API_KEY=your_key_here
```
3. Run on Android 8.0+ (API 26+)
